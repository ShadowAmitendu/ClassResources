# Security & Content Policy

## Supported Versions
Class Resources is a static web application hosted on GitHub Pages. Only the latest version on the `master` branch is actively maintained.

| Branch / Version | Supported |
| :--- | :--- |
| `master` | Yes |
| `submissions` | Yes |
| Older releases | No |

## Reporting Security Issues & Suspicious Files
We take content safety and integrity seriously. If you discover:
- A malicious, corrupted, or infected document in the resource tree
- An accidental leak of sensitive credentials, API keys, or private university data
- A copyright infringement requiring immediate removal
- A web security vulnerability in our client-side scripts or hosting configuration

Please **do NOT** open a public issue. Instead, report it directly to the project maintainer:

- **Maintainer:** Amitendu Bikash Dhusiya
- **Contact:** [https://amitendu.me](https://amitendu.me)
- **GitHub Profile:** [@ShadowAmitendu](https://github.com/ShadowAmitendu)

## Response Timeline
- We acknowledge valid security and safety reports within 48 hours.
- Confirmed issues or compromised files are remediated or purged immediately from both the working tree and commit history where necessary.
