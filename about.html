About Class Resources

A centralized, open-source academic repository designed for BCA students.

What is Class Resources?

Overview
  • Class Resources is a free, ad-free web platform and open academic archive dedicated to Bachelor of Computer Applications (BCA) students.
  • It curates verified university syllabus documents, comprehensive module-wise lecture notes, continuous assessment submissions (CA1, CA2, PCA1), seminar presentations, and previous question papers into a fast, organized, and searchable interface.

Why This Site Was Built

Motivation
  • Eliminating Scattered Notes: Before this archive, student study materials were fragmented across dozens of WhatsApp chats, Telegram groups, temporary Google Drive links, and personal pen drives.
  • Reliable Exam Prep: Finding specific module notes or question papers days before an exam was stressful and time-consuming.
  • One Bookmarkable Hub: Class Resources unifies all semester resources under a structured hierarchy (1st through 8th semester), ensuring students can find exactly what they need in seconds.

Key Features

Features
  • 1-Click Bulk ZIP Downloads: Download entire syllabus sections, subject notes, or assignment collections as clean ZIP archives in one click directly inside the browser using client-side JSZip.
  • Interactive File Explorer Tree: Folders and submodules expand with hierarchical tree guide lines, providing an intuitive desktop file manager feel right on the web.
  • Material Design 2 UI & Radial Dark Mode: Clean typography, accessible contrast, mobile-friendly navigation, and a butter-smooth radial bloom theme transition.
  • Blazing Fast & Offline Ready: Powered by static JSON indexes and hosted on GitHub Pages with zero database bottlenecks, zero advertisements, and zero tracking cookies.
