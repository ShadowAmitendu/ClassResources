Material Design 3 (Material You) Theme Refresh

November 23, 2026
  • Material 3 Color Palettes: Implemented official M3 expressive Indigo tonal tokens (#4355b9 light primary, #bac3ff dark primary) with dynamic surface containers, surface tinting, and harmonious dark mode contrast.
  • M3 Shapes & Pill Buttons: Upgraded card elevations, container borders, rounded 14px card corners, and full-pill rounded action buttons (border-radius: 9999px).
  • Nested Tree Indent Lines: Added visual file explorer tree guide lines with horizontal branches (├──) and corner turns (└──) for deep nested folders.
  • Leading App Bar Navigation: Relocated back navigation arrow to the leading position before the page title across all subpages.

UI Modernization & Semester Reorganization

November 23, 2026
  • Full UI Modernization: Rebuilt the user interface with Material Design 2 principles, fixed app bar, mobile semester dropdown selector, and circular view-transition dark mode toggle.
  • Standardized Directory Hierarchy: Reorganized repository folders into clean bca/semesters/[1st-8th]/[syllabus|notes|assignments|question-papers] layout.
  • Dynamic Semester Generator: Overhauled generate.py to automatically scan folder trees and produce individual per-semester JSON indices (1st.json through 8th.json).
  • Semester Status Notices: Added intelligent status banners notifying users about semesters under preparation (without availability guarantee) and specifically noting that 8th-semester resources cannot be added yet until the university announces the official syllabus.
  • Terms of Use & Attribution: Added Terms & Conditions detailing non-commercial educational permissions and mandatory author attribution ("must tag me").
  • SEO & Discoverability: Added sitemap.xml and robots.txt.
  • Contribution Tooling: Added GitHub issue forms for resource submissions and pull request templates for student contributors.
